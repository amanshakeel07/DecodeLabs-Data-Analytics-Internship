# Project 2: Exploratory Data Analysis (EDA)

## 📌 Folder Directory Purpose
This directory contains the codebase, automated data pipelines, and executive reporting artifacts for the **Week 2: Exploratory Data Analysis (EDA)** phase of the DecodeLabs internship. 

The purpose of this module is to move beyond initial data cleaning and execute a systematic diagnostic interrogation of our transaction records. By uncovering localized distribution behaviors, tracking seasonal revenue metrics, and analyzing multivariate dependencies, this folder delivers the mathematical foundation required before deploying downstream predictive algorithms.

---

## 📂 File Breakdown & Component Operations

This folder contains three primary asset types—the automation code (`.py`), the tracking records (`.csv`), and the formal sign-off documentation (`.pdf`). Here is what each file does:

### 1. ⚙️ `app.py` (The Automated Analytics Engine)
This Python script serves as the centralized algorithmic pipeline for our EDA. When executed, it pulls the target dataset and performs the following automated operations:
* **Descriptive Auditing:** Computes a full Five-Number Summary across numerical features to map out data bounds.
* **Skewness Modeling:** Measures geometric data distribution shapes to alert engineering teams to center-of-gravity shifts.
* **Categorical & Temporal Aggregations:** Groups transacting pools to isolate high-performing inventory and map chronological revenue tracks.
* **Statistical Visualizations:** Programmatically designs and exports six standalone charts (`.png`) utilizing targeted Seaborn design themes.

### 2. 📊 `Dataset for Data Analytics - Sheet1.csv` (The Operational Evidence Base)
This file represents the structural foundation of our project. It holds **1,200 unique historical rows and 14 individual feature columns**, capturing critical data points such as `OrderID`, `Product`, `Quantity`, `UnitPrice`, `ItemsInCart`, and `TotalPrice`. It acts as the direct data source that our `app.py` engine processes to extract actionable corporate metrics.

### 3. 📄 `Report2.pdf` (The Final Executive Milestone Report)
This is the formal corporate-grade artifact generated for submission to the DecodeLabs review board. It synthesizes our raw codebase calculations into an elite, multi-page business document. It incorporates:
* A structured alignment with the **Input-Process-Output (IPO)** engineering framework.
* Direct statistical breakdowns highlighting the critical positive skewness (`0.891`) of the revenue matrix.
* Perfectly mapped correlation annotations matching our multivariate matrix charts (`0.72`, `0.62`, `0.39`, `0.01`).
* Embedded visualization placeholders demonstrating a complete analytical portfolio.

## 📈 Visual Assets Generated by the Pipeline
Upon executing `app.py`, the script automatically populates a sub-portfolio of six diagnostic charts:
1. `total_price_distribution.png` — Visualizes univariate frequency curve shapes and right-hand skewness tails.
2. `total_price_boxplot.png` — Maps out interquartile boundaries (Q1 to Q3) and points out independent commercial outliers.
3. `monthly_sales_trend.png` — Continuous line graph tracking temporal trajectory shifts across seasonal timelines.
4. `product_revenue_comparison.png` — Ranks categorical inventory streams to highlight top revenue earners (e.g., Chairs and Printers).
5. `cart_items_vs_total_price.png` — Bivariate scatter plot mapping how transaction sizes scale relative to discrete item counts.
6. `correlation_heatmap.png` — The university-grade linear dependency matrix exposing how features shift together on a `-1.00` to `+1.00` scale.
